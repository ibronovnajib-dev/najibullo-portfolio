# Portfolio — next level checklist

The site now communicates: founder + full-stack/mobile developer, Web/Android/iOS capability, age 16, two live products, multilingual delivery, and a scope-aware 3–7 day MVP capability.

To make the portfolio substantially stronger, add proof rather than more visual effects:

1. **Real Android/iOS proof** — 3–6 screenshots or a short screen recording of each real mobile app. Do not use mockups as proof if the product is not actually built.
2. **Measurable product outcomes** — real users, transactions, jobs posted, specialists, retention, performance improvements, or launch milestones. Use only verified numbers.
3. **Case studies with decisions** — for each product: problem → your role → constraints → architecture → design decisions → implementation → result → what you learned.
4. **GitHub / LinkedIn / professional email** — link only profiles you actively maintain. A domain email such as hello@yourdomain.tj improves credibility.
5. **Real testimonials** — 2–4 short quotes from actual collaborators/clients. Include name/role only with permission. Never invent testimonials.
6. **Production quality** — custom domain, HTTPS, 404 page, sitemap, robots, OpenGraph, favicon, analytics, error monitoring and backups.
7. **Performance** — aim for strong Core Web Vitals and Lighthouse scores; compress images, preload only critical assets and keep motion GPU-friendly.
8. **Accessibility** — keyboard navigation, visible focus, reduced-motion support, alt text, contrast and semantic headings.
9. **Current CV** — keep the downloadable PDF aligned with the site: Web + Android + iOS, founder experience, projects, skills and contact details.
10. **Keep age/date current** — the visible “16” is time-sensitive. Update it when necessary or replace it later with a timeless milestone.

## Positioning rule

The portfolio should make one claim and prove it repeatedly: **I can take a digital product from idea to launch across web and mobile.** Every section should either prove product quality, engineering depth, delivery speed, or real-world impact.
